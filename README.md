# Planivo

Planivo dijital Notion ürünleri satış sitesi.

## Dosyalar
- `index.html` — ana satış sitesi
- `Planivo_Weekly_Planner_Lite.pdf` — ücretsiz Weekly Planner Lite
- `weekly-planner.html` — planner'ın yazdırılabilir web sürümü

## Yayınlama
Bu repo Netlify, Vercel veya GitHub Pages ile statik site olarak yayınlanabilir. Build komutu gerekmez; yayın kökü repo kök dizinidir.

## Güncelleme akışı
Yeni ürün, fiyat veya Shopier linki geldiğinde `index.html` güncellenir ve `main` branch'e commit edilir.
